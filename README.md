# 🌦️ Weather App

A modern and responsive **Weather Application** built using **HTML, CSS, and JavaScript**.
This app fetches real-time weather data using the **OpenWeather API** and displays it with a clean UI and dynamic visuals.

---

## 🚀 Live Demo

👉 https://faizahmad11.github.io/weather-app


---

## 📌 Features

* 🔍 Search weather by city name
* 🌡️ Real-time temperature display
* 💧 Humidity information
* 🌬️ Wind speed data
* 🌤️ Dynamic weather icons (Clear, Rain, Clouds, Mist, Snow)
* ⚡ Fast and lightweight
* 📱 Responsive design

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox + Animations)
* JavaScript (ES6)
* OpenWeather API

## ⚙️ Setup Instructions

1. Clone the repository:

```bash
git clone https://github.com/Faizahmad11/weather-app.git
```

2. Open the project folder:

```bash
cd weather-app
```

3. Open `index.html` in your browser

---

## 🔑 API Setup

This project uses OpenWeather API.

1. Go to https://openweathermap.org/api
2. Create a free account
3. Get your API key
4. Replace in `script.js`:

```js
const apiKey = "YOUR_API_KEY";
```
